# TikShan 🎵

Descargador de videos de TikTok sin marca de agua. Sin anuncios, sin registro, gratis.

## Desarrollo local

```bash
npm install
npm run dev
```

## Deploy en Vercel

1. Sube este repositorio a GitHub
2. Ve a [vercel.com](https://vercel.com) → New Project → importa el repo
3. Vercel detecta Vite automáticamente → Deploy

## Stack

- React 18
- Vite 5
- API: tiklydown.eu.org
